# Evently – Event Discovery Platform

## Project Description

Evently is a web-based platform that helps users discover, explore and register for different events, including concerts, workshops, exhibitions and university activities.

The platform provides a centralized space for users to find events that match their interests and allows organizers to manage their events.

## Problem Statement

Event information is scattered across different platforms, making it difficult for people to discover activities and access event information in one place.

Evently aims to solve this problem by providing one organized platform for event discovery and management.

## Target Audience

- University students
- Young adults
- Event enthusiasts
- Event organizers

## Main Features

1. Browse Events
2. Search by Category
3. Event Details
4. Event Registration
5. Saved Events
6. Organizer Dashboard
7. Event Creation and Management
